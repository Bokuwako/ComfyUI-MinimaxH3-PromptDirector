# POV와 카메라 대상 지정

POV는 시점 주인의 눈으로 본다는 뜻입니다. 앵글을 비우면 눈높이·수평 시선을
추가하지 않습니다. 앵글을 지정하면 POV에서는 시점 주인이 보는 각도로 해석합니다.

샷 카드의 대상 설정:

| 항목 | 의미 |
|---|---|
| 시점 주인 | POV / 어깨너머 / 밀착 시점의 기준 인물 |
| 앵글 기준 | 누구 또는 무엇을 내려다보거나 올려다보는가 |
| 방향 기준 | 누구의 정면·측면·후면을 보는가 |
| 사이즈 대상 | 누구를 클로즈업·미디엄·와이드로 담는가 |
| 모션 대상 | 카메라가 따라가거나 주위를 도는 대상 |
| 몸 방향—누가 / 어디로 | 인물의 몸이 향하는 대상. 시선과 별개 |
| 시선—누가 / 어디로 | 인물이 바라보는 대상. 몸 회전과 별개 |

촬영 대상은 `장면 전체`, `이미지 N의 인물`, 남자·여자·제3자, 직접 입력에서 고릅니다.
시점 주인은 사람이므로 `장면 전체`를 선택하지 않습니다. 시선과 몸 방향의 도착점에는
`카메라 쪽`과 `카메라 반대쪽`도 있습니다.

한 이미지에 여러 사람이 있거나 같은 사람이 여러 이미지에 있으면, 직접 입력에
브리프에서 사용하는 동일한 식별 이름을 쓰세요. 직접 입력은 자동 인물 식별 기능이 아닙니다.
특정 소품이나 본인의 손처럼 몸 일부를 대상으로 삼을 때도 직접 입력을 사용합니다.

POV의 사이즈를 사용하려면 먼저 화면에 담을 사이즈 대상을 선택하세요.
POV 주인 자신을 외부에서 보는 인물 구도나, 같은 인물의 어깨너머와 정면을 동시에
요구하면 설정 충돌로 알립니다. 시점 주인과 화면에서 보고 싶은 사람을 구분하세요.

‘같은 순간—카메라만 바뀜’은 몸 방향·시선을 이어받습니다. 카메라를 보던 시선도
이전 카메라가 있던 실제 위치를 향한 상태를 유지합니다. 몸 방향이나 시선을 바꾸는
동작이 필요하면 ‘이어지는 동작’을 사용하세요.

기존 샷 JSON은 그대로 읽으며 새 항목이 없으면 미지정으로 처리합니다.
ComfyUI 재시작 후 브라우저를 새로고침해야 새 선택 칸과 브리프가 함께 적용됩니다.
선택 내용의 전달을 검증한 변경이며 영상 모델의 POV 재현을 보장하지는 않습니다.
